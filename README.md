# NS Print Mart

Premium frontend-only Angular website for **NS Print Mart** — digital & offset printing in Colombo.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200/`

## Build

```bash
npm run build
```

Output: `dist/ns-print-mart`

## Content you can edit later

All easy-to-replace content lives in:

- `src/app/data/company.ts` — contact, hours placeholder, social placeholders
- `src/app/data/services.ts` — services catalogue
- `src/app/data/portfolio.ts` — portfolio items
- `src/app/data/testimonials.ts` — placeholder testimonials
- `src/app/data/products.ts` — featured products
- `src/app/data/finishes.ts` — finish options

Brand logo & imagery: `public/assets/`

## Notes

- Frontend only — quote form shows a demo success state (no backend send)
- Social links / opening hours are placeholders in `company.ts`
